Hero banner images go in this folder.

  1.jpg  2.jpg  3.jpg  4.jpg     slide 1-4, in the order they appear on the Home page
  <film-slug>.jpg                a specific film, e.g. the-odyssey.jpg (wins over the number)

.jpg / .jpeg / .png / .webp are all fine. About 1920x1180 px fills the banner.
A slide with no file here shows the film's backdrop from the API.
Restart `npm run dev` after adding files.
